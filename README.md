# 弦理论 · 3D 可视化

全屏、可交互的弦理论三维可视化。画面里的每个对象都由真实的解或真实的几何驱动，文字只保留一两句。

| 场景 | 画的是什么 | 依据 |
| --- | --- | --- |
| 弦的运动 | 开弦 / 闭弦在平直时空中的运动，颜色 = 速率，曲面 = 世界面 | Nambu–Goto 作用量的精确解 `X = ½[a(σ−τ) + b(σ+τ)]`，`|a′| = |b′| = 1`（Kibble–Turok 曲线族）。开弦端点恒为光速，闭弦在 `a′ = −b′` 处出现尖点 |
| 世界面 | 一根闭弦分裂成两根；可改变观察者速度，分裂事件随之移动 | 光锥图的 Mandelstam 映射 `ρ = ln(z² − 1)`，等时线是 Cassini 卵形线 |
| T 对偶 | 半径 R 与 1/R 的卷曲维度，动量 n 与缠绕 w 互换 | `M² = (n/R)² + (wR/α′)² + 振子项`，能级匹配 `N − Ñ = nw` |
| Calabi–Yau | 费马超曲面的二维截面在四维中旋转 | `z₁ⁿ + z₂ⁿ = 1`；n = 3 / 4 / 5 分别属于环面、K3、五次三维流形 |

示意成分：世界面嵌入三维时对等时线做了缩放（拓扑和等时线形状不变）；T 对偶里多圈缠绕的弦被略微错开以便看清。

## 运行

直接双击 `index.html` 即可（`app.js` 是已打包好的单文件）。

开发：

```powershell
npm install
npm run dev     # http://127.0.0.1:4173
npm run build   # 重新生成 app.js
npm test        # 数值校验：波动方程、Virasoro 约束、不超光速、T 对偶、Calabi–Yau 方程等
```

操作：拖动旋转，滚轮缩放，空格暂停，数字键 1–4 切换场景。

## 结构

- `src/physics.js`：纯物理/数学函数，不依赖渲染
- `src/scenes/*.js`：四个场景
- `src/main.js`：渲染器、辉光、界面
- `test/physics.test.mjs`：物理校验
