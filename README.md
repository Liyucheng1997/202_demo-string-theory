# 弦·万物之弦

一个用于解释“什么是弦理论”的中文交互式单页网站。页面以实时 Canvas 动画、尺度滑杆和维度展开交互，串联点粒子、量子弦、振动模态、额外维度、对偶性与 M 理论等核心概念。

## 本地运行

项目不依赖构建工具，直接打开 `index.html` 即可浏览。也可以在项目目录启动静态服务器：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。

## 文件结构

- `index.html`：页面语义结构与理论内容
- `styles.css`：科技视觉、动效与响应式布局
- `app.js`：弦动画、模态切换、尺度和维度交互

## 内容边界

页面将弦理论准确表述为量子引力的候选框架，而非已经被实验确认的自然定律；并明确区分直观类比与精确理论描述。
